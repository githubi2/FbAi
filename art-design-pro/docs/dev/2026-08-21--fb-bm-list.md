# BM 列表页（Business Manager）

日期：2026-08-21

## 功能

新增「BM管理 → BM列表」页面（`/bm-manage/list`，组件 `views/ad-account/bm/index.vue`，路由名 `AdAccountBmList`，菜单 id=16 已提前注册）。

14 列：状态、BM名称、推送状态、备注、BM类型、所有者角色、日限额、认证状态、创建时间、管理员、隐藏管理员、合作伙伴、广告账户、BM质量。

## 字段来源（全部经真实 token 实测，非猜测）

| 列 | 来源 | 说明 |
|---|---|---|
| 状态 | 派生 | 官方无 BM 状态字段；API 可达即「正常」 |
| BM名称 | `me/businesses?fields=id,name` | tooltip 显示 BM ID |
| 备注 | 本地 `remark` | 可编辑，刷新不覆盖 |
| 所有者角色 | `me/businesses?fields=permitted_roles` | 当前授权用户角色（ADMIN/EMPLOYEE），可靠；不要按名字匹配 business_users（business 显示名 ≠ 个人 profile 名） |
| 认证状态 | `verification_status` | verified / not_verified |
| 创建时间 | `created_time` | |
| 管理员 | `business_users?summary=total_count&limit=0` | **真实总数**（灰号/企业账号在 data 里不可枚举，但 summary.total_count 准确）；悬停显示可见名单 + 邀请中数（`pending_users` role=ADMIN） |
| 合作伙伴 | `owned_businesses + agencies` 边计数 | `partners` / `client_businesses` 边不存在（实测报错） |
| 广告账户 | `owned_ad_accounts + client_ad_accounts` 边计数 | |

已移除（公开 API 确认拿不到，穷尽探测 v12–v22 + 约 20 个候选字段/边）：推送状态（本地无推送功能）、BM类型、日限额、隐藏管理员、BM质量。这些数据参考工具走的是 BM 网页内部接口（Cookie 鉴权），非 Graph API。

## 架构（与广告账户管理一致：读写分离）

- `GET /api/v1/fb/bm-list` — 纯读 `fb_bm_cache` 缓存，毫秒级
- `POST /api/v1/fb/bm-list/refresh` — 显式触发后台刷新（5 分钟冷却、幂等 `{started}`）
- `PUT /api/v1/fb/bm-list/:id/remark` — 更新本地备注
- `GET /api/v1/fb/refresh-status?type=bm` — 刷新状态轮询
- 前端 onMounted：GET 立即显示 → POST refresh → 2s 轮询 → silentReload 静默替换

## DB

`migrations/009_fb_bm_cache.sql` — 唯一索引 `(fb_token_id, bm_id)`，upsert 不覆盖 remark/push_status。

## 注意
